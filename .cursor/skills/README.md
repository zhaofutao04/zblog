# zblog 写作 Skills（项目级）

在 Cursor 中可通过 `@skill名` 或描述触发。面向 `docs/_posts` 中文技术博文。

| Skill | 用途 |
| --- | --- |
| [zblog-new-tech-post](./zblog-new-tech-post/SKILL.md) | 新建文章：路径、frontmatter、开篇、分类 |
| [zblog-tech-article-structure](./zblog-tech-article-structure/SKILL.md) | 长文结构：表、图、章节、系列互链 |
| [zblog-markdown-vuepress](./zblog-markdown-vuepress/SKILL.md) | KaTeX、Mermaid、加粗、站内链、Hope 容器 |
| [zblog-editorial-pass](./zblog-editorial-pass/SKILL.md) | 去 AI 腔润色（对齐 EDITORIAL-PASS-PLAN） |
| [zblog-verify-post](./zblog-verify-post/SKILL.md) | 发布前 dev/build 与渲染自检 |

## 建议使用顺序

1. `zblog-new-tech-post` — 搭骨架  
2. `zblog-tech-article-structure` — 排章节  
3. 写作过程中遵守 `zblog-markdown-vuepress`  
4. `zblog-editorial-pass` — 通读润色  
5. `zblog-verify-post` — 构建预览后提交  

全局「去 AI 味」还可配合 `~/.cursor/skills/de-ai-writing`（不限于本仓库）。
