## 👨‍💻 个人简介

你好，我是**老Z**，一名深耕支付安全领域的技术专家。从事金融科技行业多年，专注于**支付安全**、**密码学**与**AI技术**的深度研究与实践应用。

### 🎯 专业领域

#### 💳 支付安全技术
- **PCI DSS 合规专家**：深入了解支付卡行业数据安全标准的各项要求
- **3D Secure 协议**：在线支付验证协议的技术原理与集成实践
- **国际银行卡组织**：Visa、Mastercard等七大组织的技术架构解析
- **移动支付安全**：Apple Pay、Google Pay等数字钱包的安全机制

#### 🔒 密码学与安全
- **加密算法实践**：RSA、AES等加密算法的工程应用
- **身份认证技术**：JWT、JWS、JWE 完整技术栈
- **数字签名与证书**：PKI体系和数字证书管理
- **安全架构设计**：构建安全可靠的金融系统

#### 🤖 AI大模型开发
- **Claude Code 深度实践**：MCP协议、Skills系统的高级用法
- **海外开发环境**：WireGuard + CLIProxyAPI 代理搭建
- **AI驱动开发**：探索AI工具链和最佳实践
- **多模态应用**：结合AI技术优化开发流程
